# See the map

## Purpose

Export a deterministic Mermaid or DOT projection of the territory graph for PRs and docs, optionally labeled with each node's active decision count so a reviewer sees where the recorded reasoning lives. Also provides the view-export entry used by the CLI `view` / `export` commands.

## Actor & Trigger

- **Actor:** coding agent via MCP (`if-mcp-tools`) or human/CI via CLI (`if-cli`)
- **Trigger:** `export_mindplan_view` tool or `mindplan-mcp view|export`

## Execution Logic

Package: `src/interactions/i-export-map/`

- Handler for `export_mindplan_view` (registered by `if-mcp-tools`)
- Export function callable by `if-cli` for `view` / `export` (format, focus, include_retired, output file)
- Projection substrate: `f-view-projection`
- Optional focus validation via `f-compiler-rules` `findNode`
- `decisions` (boolean, default false) is passed to the projection, which then labels each node with its active decision count; `runViewExport` accepts it too
- Automatic `mindplan/map.md` refresh after mutations is owned by `i-steer-plan` (calls `f-view-projection` directly)

Depends on: `f-territory-store`, `f-view-projection`, `f-compiler-rules`. Belongs to: `j-territory-sdlc`.

## Acceptance Criteria

- `export_mindplan_view` returns Mermaid and DOT (full or focused)
- CLI `view` / `export` produce the same diagram output as before
- Handler lives under this package; Interfaces only wire it
- `npm test` passes
- `export_mindplan_view({ decisions: true })` labels nodes with their active decision counts; without it the diagram is unchanged

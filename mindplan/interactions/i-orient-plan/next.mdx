# Orient (slim context + grouped blast radius)

## Purpose

Read-path orientation. `get_node_implementation` returns owned files (and supports path→owner lookup). `get_node_context` / `orient_for_work` context is `record` + `body` only (no `raw_context`, `context_path`, top-level title/description, or `next.raw`). Blast radius groups `affected_files` by owner and omits cancelled/deprecated nodes by default (`include_retired` opt-in). Records carry `implements` and `role`.

## Actor & Trigger

- **Actor:** coding agent or human via MCP (`if-mcp-tools`) or console API (`if-console-api`)
- **Trigger:** MCP/HTTP orient tools

## Execution Logic

Intended files: `src/interactions/i-orient-plan/`

- Keep existing query tools (`find_related_nodes`, `get_mindplan_graph`, `get_node_context`, `get_blast_radius`, `orient_for_work`, `get_node_implementation`)
- `get_node_context` / context inside `orient_for_work`:
  - Return `folder`, `current_path`, `attachments_path`, `attachments`, `record`, `body`, and when evolving `next_path`, `next_attachments_path`, `next: { record, body }`
  - Do **not** return `raw_context`, `context_path`, top-level `title`/`description`, or `next.raw`
- `get_blast_radius` / blast_radius inside `orient_for_work`:
  - `affected_files` is grouped: `[{ owner_id, owner_type, via: AffectedFileVia[], files: string[] }]`, sorted by `owner_id`; `via` values sorted; files deduped and sorted
  - Cancelled and deprecated nodes are omitted from `affected`, `journeys_at_risk`, `affected_files`, and `reachability` lists by default
  - BFS still traverses through retired nodes so a live dependent behind a retired one keeps its true hop distance
  - Optional `include_retired: boolean` (default `false`) restores retired nodes in those lists
  - Reuse `RETIRED_STATES` from `f-source-index`; do not change `blastRadiusDependents` in `f-compiler-rules`
- `get_node_implementation` unchanged (files / path lookup / Journey / Bug tagging)
- Uses `f-source-index` for expansion/universe and retired-state constants

Depends on: `f-graph-search`, `f-territory-store`, `f-compiler-rules`, `f-source-index`.

## Acceptance Criteria

- `get_node_context` and `orient_for_work.context` have no `raw_context`, `context_path`, top-level `title`/`description`, or `next.raw`
- `affected_files` is one entry per owner with `via` as an array and deduped `files`
- Cancelled/deprecated dependents are absent from blast radius by default and present when `include_retired: true`
- A live node that depends on a retired intermediate still appears with its true distance
- Verified via `npm test`

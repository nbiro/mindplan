# Orient on the plan

## Purpose

Read-path orientation for agents and humans: find the owning node, its 1-hop neighborhood, territory body, blast radius, and implementation package before coding.

## Actor & Trigger

- **Actor:** coding agent or human via MCP (`if-mcp-tools`)
- **Trigger:** MCP tool calls listed below

## Execution Logic

Package: `src/interactions/i-orient-plan/`

- Handler module(s) owning these tools (registered by `if-mcp-tools`, not by `f-mcp-runtime`):
  - `get_mindplan_graph` — full graph dump
  - `find_related_nodes` — ranked focus + 1-hop summaries
  - `get_blast_radius` — transitive dependents + `journeys_at_risk`; Interaction focus includes `reachability`
  - `get_node_context` — record + body (+ `next` when evolving)
  - `orient_for_work` — composite find + context + blast radius
  - `get_node_implementation` — prescribed package root / layout-free result
- Helpers: `buildBlastRadiusPayload`, `buildNodeContextPayload` (moved from `f-mcp-runtime/server.ts`)
- Uses `summarizeGraphNode` from `f-territory-store`; search from `f-graph-search`; reachability/blast from `f-compiler-rules`
- `tools.ts` may keep the `QUERY_TOOLS` name list for ownership documentation

Depends on: `f-graph-search`, `f-territory-store`, `f-compiler-rules`. Belongs to: `j-territory-sdlc`. Leads to: `i-steer-plan`.

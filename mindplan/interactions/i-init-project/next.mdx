# Init project

## Purpose

Scaffold consumer repos and migrate brownfield configs. Install the agent assets so that the always-on surface is small: a stub in root `AGENTS.md` and `.cursor/rules/mindplan.mdc` that makes the agent orient on the graph and defers to the MindPlan MCP server instructions. The full systems dialect is installed once, at `mindplan/agent/playbook.md`, as the fallback for hosts that do not surface server instructions. Keep the one-time migration from `implementation_packages` to `{ sources, exclude }`, seeding `implements` and Foundation `role`.

## Actor & Trigger

- **Actor:** maintainer or agent via CLI (`if-cli`)
- **Trigger:** `mindplan-mcp init` (`-f` / `--force` only; no `--layout`)

## Execution Logic

Intended files: `src/interactions/i-init-project/`

- Keep installers + `resolvePackageRoot` + `runInit` and the report shape
- `installAgentPlaybook`: unchanged — copies `templates/agent/playbook.md` to `mindplan/agent/playbook.md`
- `installRootAgentsMd`: copies `templates/agent/agents-stub.md` (not the playbook) to root `AGENTS.md`; idempotent unless `-f`
- `installCursorRule`: writes `.cursor/rules/mindplan.mdc` as `alwaysApply: true` frontmatter plus the stub body; frontmatter `description` reads “MindPlan — orient on the product graph before planning or changing code”
- Skills, integrations, MCP example, `.cursorignore`, and `.cursor/permissions.json` installers unchanged
- Migration when config still has `implementation_packages`:
  - `required` → `sources: ["src/**"]`; seed each node's implements (live + open next) from `src/<kind>/<id>/` skipping `.gitkeep`
  - `off` → `sources: []`, empty implements
  - Both: fill Foundation `role` from description prefix (Assembler/Infra/Design system/Adapter), default `infra`
  - Server-side write; shipped nodes do not need open_next for seed
- Write `{ sources, exclude }` config shape owned by `f-source-index`

Depends on: `f-territory-store`, `f-source-index`.

## Acceptance Criteria

- Fresh `init` writes `AGENTS.md` and `.cursor/rules/mindplan.mdc` whose bodies equal the stub template, and `mindplan/agent/playbook.md` equal to the playbook template
- `init -f` overwrites an existing full-playbook `AGENTS.md` and Cursor rule with the stub
- `init` without `-f` leaves an existing `AGENTS.md` untouched
- Init migrates old configs and seeds implements/role
- No `--layout` flag remains
- Verified via `npm test` / smoke

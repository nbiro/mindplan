# Init project

## Purpose

Init installs the playbook, project brief, and host copies for the chosen host (Cursor, Claude Code, or both). It ignores the `mindplan/` tree in Cursor (`.cursorignore` → `mindplan/**`) and writes a missing mirror for each already-shipped pipeline node.

## Actor & Trigger

- **Actor:** human via CLI
- **Trigger:** `mindplan-mcp init [--host cursor|claude|all]`

## PRD / Execution Logic

Intended files: `src/interactions/i-init-project/`

- `runInit` takes `hosts` (default `["cursor"]`) and installs only the chosen host copies
- Cursor host: `.cursorignore`, `.cursor/skills/`, `.cursor/rules/mindplan.mdc`, `.cursor/permissions.json`
- Claude Code host: `CLAUDE.md` containing `@AGENTS.md`, and `.claude/skills/mindplan-*`; an existing `CLAUDE.md` is kept unless `--force`
- The report carries `cursor` and `claude` groups that are present only when selected
- `backfillMirrorTwins` after installers
- Graph-load failures during backfill are skipped (incomplete migration fixtures)
- **Version stamp.** Init reads `mindplan/version.json` before installing. Package-owned files (the playbook, both skills, `mcp.json.example`, `integrations/`, the host skill copies, and `.cursor/rules/mindplan.mdc`) are rewritten when the stamp is missing, unreadable, or older than the package, as if `--force` were passed for those files only. Repo-owned files (`AGENTS.md`, `CLAUDE.md`, `.cursorignore`, `.cursor/permissions.json`, `mindplan/project.md`) still change only with `--force` (the brief never).
- A stamp newer than the package is `Blocked:` before any write (upgrade `mindplan-mcp`, or pass `--force` to downgrade the tree).
- After the installers and migrations succeed, init writes the stamp with the running package version and graph format. The report carries `version: { from, to, refreshed }` (`from` is null when there was no stamp).

Depends on: `f-territory-store`, `f-source-index`.

## Acceptance Criteria

- Init backfills missing mirrors
- `--host claude` installs `CLAUDE.md` and `.claude/skills/` and no Cursor files
- `--host all` installs both hosts; the default still installs Cursor only
- Host ignore covers the whole mindplan tree for Cursor
- Init stamps `mindplan/version.json`; a rerun with an older stamp refreshes package-owned files and leaves repo-owned files alone
- Init refuses a stamp newer than the package unless `--force`
- Verified via `npm test`

# Integrity check (released live presence)

## Purpose

Offline audit for CI and agents. Default mode loads the graph and enforces file ownership: exclusivity, coverage, presence, leftovers, and the import matrix. When a pipeline node has an open next, live presence **skips** implements entries that next has released (via `releasedClaimEntries` from `f-source-index`). Opt-in `--base` applies lifecycle dirty-src rules using the implements index.

## Actor & Trigger

- **Actor:** CI, agent, or maintainer via CLI (`if-cli`)
- **Trigger:** `mindplan-mcp check` / `node dist/index.js check`

## Execution Logic

1. Load `mindplan/config.json` via `f-source-index` (`sources`/`exclude`; missing → `["src/**"]`; stale `implementation_packages` → Blocked → init).
2. Default check: graph load + exclusivity + coverage + presence + leftovers + import matrix (using compiler reachable-Foundations / role rules).
3. **Presence (live):** when the node is `in-review` or production (`stable`/`unstable`), require each live `implements` entry on disk **except** entries returned by `releasedClaimEntries` when `next` is open. Kept entries (still listed by next, or overlapping expanded files) are checked as before. Nodes without next keep today’s full live presence.
4. **Presence (next):** unchanged — required when `next.state === "in-review"`. Ship/in-review gate in `f-compiler-rules` still requires the active slot’s entries to exist.
5. Coverage and exclusivity unchanged. A deleted released file simply drops out of the universe.
6. `--base <ref>`: dirty-src lifecycle via implements index; fail closed on git errors.

Intended files: `src/interactions/i-check-integrity/`

Depends on: `f-territory-store`, `f-compiler-rules`, `f-mcp-runtime`, `f-source-index`.

## Acceptance Criteria

- Stable node with open next that relocates implements: deleted released live entries do not fail presence
- Live entries next still keeps: missing on disk still fails presence
- Next in-review with missing next entry: still fails next presence
- After discard_next (or no next): missing live entries fail presence again
- Coverage, exclusivity, leftovers, import matrix, and `--base` behavior unchanged
- Exit 0/1 with `Blocked:` lines

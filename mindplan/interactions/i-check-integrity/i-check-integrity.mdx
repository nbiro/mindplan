# Check integrity

## Purpose

Default check Blocks a shipped pipeline node whose next file is missing or is not a state-only twin (`state: mirror`). Open evolutions skip the mirror check.

## Actor & Trigger

- **Actor:** human or CI via `mindplan-mcp check`
- **Trigger:** CLI check

## PRD / Execution Logic

Intended files: `src/interactions/i-check-integrity/`

- `checkMirrorTwins` after presence checks
- Uses `mirrorDriftReason` from the territory store

Depends on: `f-territory-store`, `f-compiler-rules`, `f-mcp-runtime`, `f-source-index`.

## Acceptance Criteria

- Missing or drifted mirror Blocks
- Open evolution does not fail the mirror check
- Verified via `npm test`

# CLI

## Purpose

CLI Interface for `mindplan-mcp` subcommands. Drops `--layout`. Init reporting mentions sources migration. Owns argv parsing, help, output, exit codes only.

## Kind

CLI command surface.

## Exposed Interactions

- `i-init-project` — `init` (`-f` / `--force`; no `--layout`)
- `i-check-integrity` — `check` (default ownership; `--base` opt-in)
- `i-export-map` — `view` / `export`

## Spec

Intended files: `src/interfaces/if-cli/`

- Remove `--layout` parsing and help
- Print init migration report from `runInit` when applicable
- When init stops after applying some renames, print those lines before the error
- `check` and `view` print `Removed <legacy> (kept <id-named>)` on stderr when a legacy file was deleted during the command

## Acceptance Criteria

- `--layout` is an unknown option
- Help documents sources-oriented init/check
- No domain logic under this Interface
- Verified via smoke


## Impact

Commands, flags, and exit codes are unchanged. Init’s closing tips change to match the stub install: the tip shown when an existing `AGENTS.md` was kept now tells the maintainer to add the MindPlan stub (orient first, follow the MCP server instructions) rather than reference the full playbook. The tip claiming Plan Review (`draft → ready`) is mandatory is removed — it was already false after self-ready shipped. The `--base` help line describes the same opt-in dirty-src check.

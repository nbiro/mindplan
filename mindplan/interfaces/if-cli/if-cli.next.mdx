# CLI

## Purpose

CLI Interface for `mindplan-mcp` subcommands. Owns argv parsing, help, output, and exit codes only. Init takes `--host cursor|claude|all` to choose which host copies it installs.

## Kind

CLI command surface.

## Exposed Interactions

- `i-init-project` — `init` (`-f` / `--force`, `--host cursor|claude|all`; no `--layout`)
- `i-check-integrity` — `check` (default ownership; `--base` opt-in)
- `i-export-map` — `view` / `export`

## Spec

Intended files: `src/interfaces/if-cli/`

- `--host` accepts `cursor`, `claude`, or `all`; default `cursor`; any other value is `Blocked: unknown init host`
- Print one line per installed host copy, grouped by host
- Remove `--layout` parsing and help
- Print init migration report from `runInit` when applicable
- When init stops after applying some renames, print those lines before the error
- `check` and `view` print `Removed <legacy> (kept <id-named>)` on stderr when a legacy file was deleted during the command

## Acceptance Criteria

- `--host claude` and `--host all` work; an unknown host exits non-zero with a Blocked message
- Help documents `--host`
- `--layout` is an unknown option
- No domain logic under this Interface
- Verified via smoke

## Impact

Init gains the `--host` flag. Existing invocations behave as before because the default host is Cursor.

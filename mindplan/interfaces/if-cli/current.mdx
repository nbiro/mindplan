# CLI commands

## Purpose

CLI Interface for `mindplan-mcp` subcommands. Owns argv parsing, help text, stdout/stderr, and exit codes; dispatches to init, check, and view/export Interactions.

## Kind

CLI command surface — `mindplan-mcp` argv subcommands.

## Exposed Interactions

- `i-init-project` — `init` (including `--layout`, `-f` / `--force`)
- `i-check-integrity` — `check` (default graph+packages; `--base` opt-in dirty-src)
- `i-export-map` — `view` / `export` diagram commands

## Spec

Package: `src/interfaces/if-cli/`

- Owns argument parsing, help text, stdout/stderr, and exit codes for `init`, `check`, `view` / `export`, and top-level `help`
- Calls Interaction entrypoints (`runInit`, `runIntegrityCheck`, export helpers) — does not reimplement them
- Invoked by `f-mcp-runtime` boot when `process.argv[2]` is a known command
- Note: `view`/`export` uses `-f` as `--format`; `init` uses `-f` as `--force` — different commands

Depends on: `f-mcp-runtime`. Exposes: `i-init-project`, `i-check-integrity`, `i-export-map`.

## Acceptance Criteria

- CLI help, exit codes, and output strings match pre-split behavior (no `--for-main`)
- `init` / `check` / `view` / `export` dispatch to the correct Interaction
- No domain installers or integrity math live under this Interface package
- `npm test` / smoke CLI cases pass

# Console API

## Purpose

HTTP Interface for the MindPlan console. Maps compiler `Blocked:` errors to structured JSON, returns `changed_files` on successful mutations, and mounts the orient and steer Interactions that the cancelled `f-console-bridge` used to wrap incorrectly as an infra Foundation.

## Kind

REST / App Router HTTP endpoints (Next.js route handlers).

## Exposed Interactions

- `i-orient-plan` — read/orient operations for the console
- `i-steer-plan` — mutate operations for the console

## Spec

- Route handlers under the Next.js app that call orient/steer handlers
- Transport only: status codes + JSON for Blocked; no domain graph logic
- Mounted by `f-nextjs` assembler
- Console UI Interactions talk to this surface via `f-console-client`, not by importing Interaction handlers

Depends on: `f-nextjs`. Exposes: `i-orient-plan`, `i-steer-plan`.

## Acceptance Criteria

- Blocked: surfaces as structured JSON errors
- Successful mutations include `changed_files`
- No Interaction domain logic lives in this Interface
- Plan-only in this change-set (stops at ready; no console code yet)

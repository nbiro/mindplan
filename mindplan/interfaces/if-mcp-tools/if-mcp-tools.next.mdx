# MCP tools

## Purpose

MCP stdio Interface that registers orient, steer, and export tools, including separate project description and rules writes, config, and attachments. Twenty-two-tool surface.

## Kind

MCP tool surface (stdio).

## Exposed Interactions

- `i-orient-plan` — read/orient tools including `get_project`
- `i-steer-plan` — mutate tools including territory, project description, project rules, config, attachments
- `i-export-map` — `export_mindplan_view`

## Spec

Intended files: `src/interfaces/if-mcp-tools/`

- Register `patch_project_description`, `patch_project_rules`, `patch_config`, `put_attachment`, `remove_attachment`
- Update `open_next` / `discard_next` / `patch_node_territory` descriptions for the twin model
- Report removed legacy paths on tool results

Depends on: `f-mcp-runtime`, `f-domain-model`, `f-graph-search`, `f-view-projection`.

## Acceptance Criteria

- Twenty-two tools registered
- `patch_project` is not registered
- Descriptions match MCP-only + twin lifecycle
- Verified via `npm test`

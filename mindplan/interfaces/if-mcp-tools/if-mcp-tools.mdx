# MCP tools

## Purpose

MCP stdio Interface that registers orient, steer, and export tools. Mounts `get_project` from `i-orient-plan` (playbook + brief). Thin wiring only. Seventeen-tool surface.

## Kind

MCP tool surface (stdio).

## Exposed Interactions

- `i-orient-plan` — read/orient tools including `get_project`
- `i-steer-plan` — mutate tools including `set_implementation_files`
- `i-export-map` — `export_mindplan_view`

## Spec

Intended files: `src/interfaces/if-mcp-tools/`

- Register `get_project` with empty input; description says playbook + brief, call before answering or writing code
- Do not register `get_playbook`
- No domain logic in this package
- After each tool call, attach deleted legacy paths as `removed_legacy_files` and append them to `changed_files` when that array is present. On a tool error, append `Removed <legacy> (kept <id-named>)` lines.

Depends on: `f-mcp-runtime`, `f-domain-model`, `f-graph-search`, `f-view-projection`.

## Acceptance Criteria

- `get_project` is registered and callable over MCP
- Seventeen-tool surface matches SPEC §8
- A tool result that deleted a legacy territory file lists that path in `removed_legacy_files` and in `changed_files` when the result has `changed_files`
- Verified via `npm test`

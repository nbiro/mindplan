# MCP tools

## Purpose

MCP stdio Interface that registers orient, steer, and export tools. Mounts `set_implementation_files`. Passes `include_retired` through to `get_blast_radius`. Tool descriptions match the slim orient / blast-radius payloads owned by `i-orient-plan`.

## Kind

MCP tool surface (stdio).

## Exposed Interactions

- `i-orient-plan` — read/orient tools (including file queries and slim blast radius)
- `i-steer-plan` — mutate tools including `set_implementation_files`
- `i-export-map` — `export_mindplan_view`

## Spec

Intended files: `src/interfaces/if-mcp-tools/`

- Register `set_implementation_files` with Zod schema (`node_id`, `files`, optional `slot`)
- `get_blast_radius` input schema: `node_id` plus optional `include_retired: boolean` (default false); pass through to `i-orient-plan`
- Update tool descriptions for `get_node_context`, `orient_for_work`, and `get_blast_radius` so they no longer mention `raw_context` / per-file `affected_files` rows, and document grouped files + retired filter
- Mount only; no domain logic
- Depends on `f-mcp-runtime`, `f-domain-model`, `f-graph-search`, `f-view-projection` for schemas/types already imported

## Acceptance Criteria

- `get_blast_radius` accepts optional `include_retired` and forwards it
- Tool descriptions match the slim payloads
- Existing tools keep names/envelopes; no domain logic under this Interface
- Verified via `npm test`

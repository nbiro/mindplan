# Agent hook

## Purpose

The project rule "read and write `mindplan/` only through the MindPlan tools" is prose; an agent under pressure greps node files anyway. This Foundation turns it into a client-side gate for Claude Code: a `PreToolUse` hook that denies host file tools on `mindplan/**` and names the MindPlan tool to use instead.

## Shared Substrate Spec

Intended files: `src/foundations/f-agent-hook/hook.ts`. No dependency on other Foundations (fs and path only).

- `HOOK_COMMAND` `npx --no-install mindplan-mcp hook pre-tool-use`, `HOOK_MATCHER` `Read|Edit|MultiEdit|Write|Grep|Glob|NotebookEdit`, `HOOK_SETTINGS_PATH` `.claude/settings.json` (under the project root).
- `isClaudeCodeProject(root)`: the root has `.claude/` or `CLAUDE.md`. `hookInstalled(root)`: some PreToolUse hook command contains `mindplan-mcp hook pre-tool-use`.
- `installHook(root)`: merges `{ matcher, hooks: [{ type: "command", command }] }` into `hooks.PreToolUse`, creating the file when missing and keeping every other key and hook; idempotent; Blocked (nothing overwritten) on invalid JSON or a `hooks` / `PreToolUse` of the wrong type. Rewrites the file as 2-space JSON.
- `hookReply(root, install)`: the `hook` field `setup_project` and `upgrade_project` return — `{ installed: true, path }`, `{ installed: false, offer }` in a Claude Code project without it, or none — and the `changed_files` entry when it wrote.
- `preToolUseDecision(input, cwd)`: the deny JSON (`hookSpecificOutput.permissionDecision: "deny"` with a reason naming `get_node_context` / `find_in_node` / `search_graph` / `get_mindplan_graph` for reads, `patch_node_territory` / `patch_node_rules` / `patch_project_rules` for writes) when the tool's target (`file_path`, `notebook_path`, Grep/Glob `path`, or the literal folder of a Grep `glob` / Glob `pattern`) is inside a `mindplan/` folder holding `version.json` or `project.md`; null otherwise and on malformed input. Backslashes and Git Bash `/d/...` paths are handled; comparison is case-insensitive on win32.
- Used by `i-setup-project`, `i-upgrade-graph` (install, status) and `if-cli` (`mindplan-mcp hook pre-tool-use`).

## Acceptance Criteria

- Installing twice writes once and keeps existing settings and hooks
- The hook denies `Read mindplan/x.mdx` and allows `src/x.ts`; malformed input prints nothing
- Verified by `rule-checks.test.mjs`

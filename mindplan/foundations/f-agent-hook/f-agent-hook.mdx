# Agent hook

## Purpose

The rule "write `mindplan/` only through the MindPlan tools" is prose; an agent under pressure edits a node file directly anyway. This Foundation turns it into a client-side gate for Claude Code: a `PreToolUse` hook that denies host file writes on `mindplan/**` and names the MindPlan tool to use instead. Reads (Read, Grep, Glob) stay free: the server's guarantees hang on the write path.

## Shared Substrate Spec

Intended files: `src/foundations/f-agent-hook/hook.ts`. No dependency on other Foundations (fs and path only).

- `hookCommand(root)`: `HOOK_COMMAND` (`npx --no-install mindplan-mcp hook pre-tool-use`) when the project has `mindplan-mcp` in its `node_modules`, else `npx -y mindplan-mcp@<this package's version> hook pre-tool-use` for a project that runs the server through npx alone; an installed hook is recognized in either form. `HOOK_MATCHER` `Edit|MultiEdit|Write|NotebookEdit`, `HOOK_SETTINGS_PATH` `.claude/settings.json` (under the project root).
- `isClaudeCodeProject(root)`: the root has `.claude/` or `CLAUDE.md`. `hookInstalled(root)`: some PreToolUse hook command contains `mindplan-mcp hook pre-tool-use`.
- `installHook(root)`: merges `{ matcher, hooks: [{ type: "command", command }] }` into `hooks.PreToolUse`, creating the file when missing and keeping every other key and hook; idempotent; Blocked (nothing overwritten) on invalid JSON or a `hooks` / `PreToolUse` of the wrong type. Rewrites the file as 2-space JSON.
- `hookReply(root, install)`: the `hook` field `setup_project` and `upgrade_project` return — `{ installed: true, path }`, `{ installed: false, offer }` in a Claude Code project without it, or none — and the `changed_files` entry when it wrote.
- `preToolUseDecision(input, cwd)`: the deny JSON (`hookSpecificOutput.permissionDecision: "deny"` with a reason naming `patch_node_territory` / `patch_node_rules` / `patch_project_rules`) when an Edit, MultiEdit, Write, or NotebookEdit targets (`file_path`, `notebook_path`, or `path`) a file inside `<root>/mindplan/` or inside a `mindplan/` folder holding `version.json`; null for every other tool (Read, Grep, and Glob included, so a hook installed with the older, wider matcher allows reads too) and on malformed input. Backslashes and Git Bash `/d/...` paths are handled; comparison is case-insensitive on win32.
- Used by `i-setup-project`, `i-upgrade-graph` (install, status) and `if-cli` (`mindplan-mcp hook pre-tool-use`).

## Acceptance Criteria

- Installing twice writes once and keeps existing settings and hooks
- The hook denies an Edit or Write of a node file under `mindplan/` and allows Read, Grep, and Glob there; malformed input prints nothing
- Verified by `rule-checks.test.mjs`

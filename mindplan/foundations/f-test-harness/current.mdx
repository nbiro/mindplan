# Test harness (released presence)

## Purpose

Regression suite for MindPlan file ownership. Extends `check.test.mjs` so a stable node can relocate files through an open next without duplicating the old path until ship.

## Shared Substrate Spec

Intended files: `src/foundations/f-test-harness/`

- Keep existing exclusivity, coverage, presence, leftovers, import matrix, dirty-src, and smoke coverage.
- Add presence cases for released live entries:
  1. Stable node, open next pointed at a new directory, old directory deleted → default check passes.
  2. A live entry next still lists, then deleted → `presence:` fails.
  3. Next in-review with a missing next entry → `presence:` fails on the next slot.
  4. Same stable node with no next (or after `discard_next`) and a missing live entry → `presence:` fails again.

Depends on: `f-mcp-runtime`.

## Acceptance Criteria

- New released-presence cases pass under `npm test`
- Existing ownership and import-matrix cases still fail closed when violated

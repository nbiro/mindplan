# Test harness

## Purpose

Regression suite for MindPlan. Assert MCP `initialize` instructions are the short `get_project` pointer, and that `get_project` returns the bundled playbook with the project brief and the sentence that names the check. The ergonomics suite covers what keeps an agent's session small and honest: the check is reachable and gates shipping, claims report their import fixes, a registry can mount Interfaces, writes return little by default, one section can be patched, a whole open set ships in one call, drift is classified, and stale text warns. The decisions suite covers that recorded reasoning survives and reaches the next agent: records round-trip through every slot move, inherit like rules, supersede without rewriting, and the gate asks for a decision only where one is costly. The shipped-claims suite covers that a shipped node grows in place only inside a folder no one else can own and that the addition stays visible until the body names it; the change-neighbors suite covers that a change sees every shipped node it edits in place and that its labels go away with it.

The sandbox git ignores the developer's global and system config

- `honesty.test.mjs`: the Coverage fix for a shipped owner is the claim alone in a folder it dominates and opens the evolution first in a subfolder it does not

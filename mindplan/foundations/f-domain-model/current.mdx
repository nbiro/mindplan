# Domain model (implements + role)

Infra — shared TypeScript taxonomy for MindPlan nodes, edges, pipeline states, and the optional `next` evolution slot. Adds server-owned `implements: string[]` on Interaction/Interface/Foundation (current and open next) and Foundation `role` (`assembler` | `infra` | `design-system` | `adapter`).

# Domain model

## Purpose

Infra — shared TypeScript taxonomy for MindPlan nodes, edges, pipeline states, the standing next-file `mirror` twin, and open evolutions. Adds `MIRROR_STATE` / `isMirrorState`. Discover must not set `node.next` for a mirror twin. `GRAPH_VERSION` stays `1`.

## Shared Substrate Spec

Intended files: `src/foundations/f-domain-model/`

- `types.ts` — `NODE_TYPES`, edges, state machines, `MindPlanNode` / `NextSlot`
- `MIRROR_STATE` (`mirror`) and `isMirrorState` — next-file twin state, not a pipeline state
- `NextSlot` remains draft|ready|in-progress|in-review only
- `node.next` means an open evolution; a standing twin does not populate it

Depends on: none.

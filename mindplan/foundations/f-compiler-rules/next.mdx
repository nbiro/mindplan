# Compiler rules (impact section shape)

## Purpose

Infra — MindPlan compiler. Keep the shipped gates: Completion Check, Open Checklist While Building, Minimum Territory Shape, Interaction Independence, Infrastructure First, Behavior First, cancel gates, force_unship, reachability, non-empty existing `implements` on `in-review` and `ship`, and the import-matrix closure that stops at assemblers.

Add one shape rule: when `## Impact` is present, it must be real prose. An empty or scaffold section fails Minimum Territory Shape on leaving `draft`, entering `in-review`, and `ship` / `resolved`. Absence of the heading is not a compiler error; Reviewers reject a neighbor that lacks it.

Open Checklist While Building keeps rejecting a checklist the evolution just finished. An open `next` whose checkbox labels match an already-complete live `current` checklist is inherited, so that case stays allowed while `next` is `draft`, `ready`, or `in-progress`. A `next` checklist with different labels that is fully checked while building still fails.

Section extraction treats `\r\n` and a lone `\r` as newlines before it splits on `##`, so a trailing `## Impact` is visible when the file uses carriage returns.

## Shared Substrate Spec

Intended files: `src/foundations/f-compiler-rules/`

- Keep Completion Check, Open Checklist While Building, Minimum Territory Shape, Independence, Infrastructure/Behavior First, cancel gates, force_unship, reachability
- Keep: `in-review` and `ship` require a non-empty `implements` list on the active slot with every entry present on disk
- Keep helpers for reachable Foundations (transitive `depends_on`; do not continue past `role: assembler`; while next is open, live and next edges both count)
- Keep import-matrix predicates consumed by `i-check-integrity`
- New: if the active body contains `## Impact`, reject an empty or scaffold section with `Blocked: Minimum Territory Shape. "<id>"/<file> section "## Impact" is empty or a stub. Write what this node adapted so the already-shipped contract still holds.`
- New: `isInheritedCheckedChecklist` is true only when the node has `shipped_at`, both the live `current` checklist and the open `next` checklist are complete, and their checkbox labels are the same non-empty set. `assertOpenChecklistWhileBuilding` returns without error in that case. Any other complete checklist while building still fails.
- New: `extractSection` normalizes `\r\n` and a lone `\r` to `\n` before splitting lines, then reads from the heading through the next `##` or the end of the body.
- Uses `f-source-index` for claim expansion and path presence

Depends on: `f-domain-model`, `f-territory-store`, `f-source-index`.

## Acceptance Criteria

- `in-progress` → `in-review` Blocked when implements empty or missing on disk
- `ship` Blocked under the same implements gate
- Assembler stops transitive Foundation reachability for import allowance
- A present empty or scaffold `## Impact` section is Blocked on `ready`, `in-review`, and `ship`
- A body with no `## Impact` heading still passes shape when the other required sections are real
- An open `next` whose labels match an already-complete live checklist may stay fully checked while `draft`, `ready`, or `in-progress`
- A `next` checklist with different labels that is fully checked while building is still Blocked
- A body whose lines are separated by a lone `\r`, with an empty `## Impact`, is Blocked for that stub rather than treated as a missing heading
- Verified via `npm test`

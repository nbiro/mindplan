### d-description-check-warn-only

- Decision: Description quality is checked with loose heuristics (empty or title-repeating, over 300 characters, an Interaction with no actor word, revision wording) that only warn.
- Alternatives:
  - Block in-review on a bad description (an actor word list cannot judge every phrasing, and a false Block stops work)
- Why: Descriptions are what search ranks and orientation shows, so bad ones cost every agent later; but the checks are guesses and must never stop work.
- Consequences: Existing graphs with long descriptions see warnings until they are shortened.

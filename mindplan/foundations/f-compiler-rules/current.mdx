# Compiler rules engine

## Purpose

Infra — the MindPlan compiler. Every graph mutation that can change state or edges is validated here; violations throw `Blocked: …` and must not be retried blindly. Includes Rule 10 force-unship recovery, pre-ship `cancelled` abandon gates, Interaction Independence, Interface exposure gates, Infrastructure First / Behavior First at ship, **Completion Check at ship/resolved only**, **Open Checklist While Building** (reject completing all checkboxes while draft/ready/in-progress or Bug open/triaged/fixing — agent must advance to in-review themselves; no auto-advance), Minimum Territory Shape, and reachability helpers.

## Shared Substrate Spec

Package: `src/foundations/f-compiler-rules/`

- `rules.ts` — taxonomy validateLink; Ghost / Infrastructure First / Behavior First; status transitions
- **Completion Check (Rule 5)** — Foundation/Interaction/Interface MUST NOT `ship` while unchecked boxes remain on the active slot; Bug MUST NOT `resolved` while unchecked remain. Does **not** gate `in-review` (agents enter review with open DoD items, then tick them in `in-review`)
- **Open Checklist While Building** — when a territory body patch / checkbox toggle would leave ≥1 checkbox and 0 unchecked while the active slot is `draft`/`ready`/`in-progress` (or Bug `open`/`triaged`/`fixing`), reject with `Blocked:` telling the agent to `update_node_status` → `in-review` first (or leave ≥1 Atomic Op open). No auto-advance
- Minimum Territory Shape, cancel gates, open_next/ship-promote, force_unship, reachability helpers unchanged in spirit from prior next

Depends on: `f-domain-model`, `f-territory-store`.

## Acceptance Criteria

- `in-progress` → `in-review` succeeds with unchecked Atomic Ops still present
- `ship` / Bug `resolved` still Blocked when unchecked remain
- Completing the last checkbox (or body replace that clears all `[ ]`) while draft/ready/in-progress (or Bug fixing/open/triaged) is `Blocked:` with guidance to advance state; state is not auto-changed
- Completing all checkboxes while `in-review` succeeds
- Verified via `npm test`

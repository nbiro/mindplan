# Framework docs

## Purpose

Infra — SPEC, playbook, and skills: MCP is the only writer of `mindplan/`; shipped next files stay as `mirror` twins. Twenty-two MCP tools. Interaction Purpose names the constraint a later session would otherwise simplify away, so a plan cannot be only a tool list. At handoff the playbook requires the graph to match the implementation, and a ship when that implementation is done and a merge is requested.

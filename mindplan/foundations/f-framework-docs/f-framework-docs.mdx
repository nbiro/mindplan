# Framework docs

## Purpose

Infra — SPEC, playbook, and skills. Project rules are mandatory via `get_rules` before each action. Tool descriptions carry when-to-call hints. New-feature code waits until nodes are updated or created through the plan-project skill. Without those constraints, a long session would treat the graph as session-start only.

- Never paste rules, playbook, or description into MCP instructions

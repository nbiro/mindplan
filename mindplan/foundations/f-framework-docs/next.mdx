# Framework documentation

## Purpose

Own MindPlan’s normative documentation so agents stay on the **system** (anti-drift / systems thinking) and run a light **agent development process** with independent review before code reaches the human. Always-on playbook is a short systems dialect — not a waterfall of Never-do lists that duplicate the compiler.

## Shared Substrate Spec

Docs live at repo root and under `templates/agent/` / `mindplan/agent/`. Package folder `src/foundations/f-framework-docs/` is a pointer (no runtime TS).

Surfaces:

- `SPEC.md` — normative taxonomy, compiler gates (including Minimum Territory Shape), Territory Completeness (semantic), package ownership
- `AGENTS.md` / `templates/agent/playbook.md` / `mindplan/agent/playbook.md` / `.cursor/rules/mindplan.mdc` — **systems dialect** always-on playbook (byte-identical mirrors)
- `templates/agent/skills/review-work/` (+ mirrors) — subgraph Plan Review + **revision-bound change-set** Implementation review
- `define-entities` / `plan-project` / `code-review` skills — on demand
- `README.md` — product framing

Canonical edits: `templates/agent/`; mirrors stay in sync.

### Always-on dialect

1. Orient via `orient_for_work`
2. Place work on the graph; MCP structure / file-tool prose
3. `Blocked:` = hard failure — classify cause, then fix
4. Own package (or layout-free logical ownership)
5. Shipped change: blast radius + `open_next`
6. Do not self-`ship` / self-`resolved` — one independent Reviewer per immutable revision

Trust mutation `anchor` after writes; no mandatory re-orient after every link.

### Review (quality gate)

- Plan Review: frozen subgraph membership → per-node `ready`
- Implementation review: freeze `{base_sha, head_sha, clean_tree, changed_files, node_ids}`; review all before any ship; ordered Foundations → Interactions → Interfaces; void on dirty tree / failed transition / post-verdict change
- Full Procedure B contract retained (AC, tests, Fit, Completeness, hygiene, general code review)

### Package ownership

Interaction owns body; Interface mounts/wires. One Interface per actor surface.

## Acceptance Criteria

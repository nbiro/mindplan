# Console client

## Purpose

Adapter — typed HTTP client the console shell and Interactions use to call `if-console-api` (orient/steer routes). Replaces the cancelled `f-console-bridge` dependency for UI nodes so they never import Interaction handlers directly.

## Shared Substrate Spec

- Typed fetch/client wrappers for orient and steer HTTP routes
- Surfaces Blocked JSON as thrown/structured errors for UI
- No graph I/O of its own; no MCP stdio

Depends on: none required for the plan reshape (HTTP only). Consumers: `f-console-shell` and console Interactions.

## Acceptance Criteria

- Console Interactions depend on this client instead of any Foundation that imports Interaction handlers
- Client is transport-only
- Plan-only in this change-set (stops at ready)

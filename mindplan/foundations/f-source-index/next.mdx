# Source index (released claim entries)

## Purpose

Infra — the file-ownership substrate. Owns `mindplan/config.json` shape `{ sources, exclude }`, the file universe, claim expansion from `implements` entries, ownership buckets (live / next / released / retired), a **claim-entry release helper** for presence, and a static import lexer/resolver so check and queries can map files ↔ owners without prescribed folders.

## Shared Substrate Spec

Intended files: `src/foundations/f-source-index/`

- **Config** — load/write `{ sources: string[], exclude: string[] }`; missing config → `sources: ["src/**"]`; brownfield may start `[]`; config still containing `implementation_packages` → `Blocked:` pointing at `mindplan-mcp init`.
- **File universe** — git-visible files (tracked + untracked not ignored) matching sources minus exclude; without git, directory walk. Ignore `.gitkeep`.
- **Claim expansion** — expand directory claims ending in `/` to exact files; reject `..` and anything under `mindplan/`. Missing paths omit from expansion (presence is checked separately).
- **Ownership index** — `buildOwnershipIndex` maps expanded files into live / next / released / retired. Exclusivity uses live ∪ next; coverage uses all four.
- **Released claim entries** — `releasedClaimEntries(node, root)` returns the subset of live `implements` **entries** (not expanded files) that an open next has released, so presence can skip them without a second release definition:
  - Normalize with `validateClaimPath`.
  - An entry next still lists exactly is **kept**.
  - Otherwise expand that one entry and expand `next.implements`. The entry is **released** when every expanded file is absent from next’s expanded set.
  - A missing/empty entry expands to nothing; it is released when next does not list that same claim (directory already moved off disk).
  - No next → empty set (discard restores live presence by recomputation).
- **Lexer / resolver** — in-house import lex and resolve as today.

Depends on: `f-domain-model` only.

## Acceptance Criteria

- `releasedClaimEntries` is the single release rule used by integrity presence
- Kept live entries are not returned; missing released directories are returned
- No next → empty; discard needs no extra state
- Config, universe, expand, ownership, lexer, and resolver remain the substrate for check/steer/orient/init
- Verified via `npm test`

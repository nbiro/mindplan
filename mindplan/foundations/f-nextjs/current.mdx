# Next.js assembler

## Purpose

Assembler — Next.js App Router shell that mounts console page Interfaces and the `if-console-api` HTTP routes. Owns app bootstrap and routing composition — not stakeholder use-case behaviour.

## Shared Substrate Spec

- App Router entry and layout primitives for the MindPlan console
- Mount points for console page Interfaces (`if-console-*`) and `if-console-api` route handlers
- Local-dev conventions (project root env / launch) consumed by `f-console-shell`
- MUST NOT own status-board, graph-explore, territory, mutate, or model screens — those are Interactions

## Acceptance Criteria

- Console page Interfaces and console API routes can be mounted in App Router
- Assembler stays free of product use-case logic

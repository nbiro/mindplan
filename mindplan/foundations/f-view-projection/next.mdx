# View projection (map legend)

## Purpose

Infra — deterministic Mermaid/DOT projection of the territory graph, plus `persistMindPlanMap` for the auto-refreshed `mindplan/map.md` snapshot after mutations.

This evolution adds a one-line plain-language legend under the `# MindPlan map` heading so vibecoders and agents can read the auto-generated map using the shared glossary (area / action / entry point / building block / bug). Projection APIs and diagram content stay unchanged.

## Shared Substrate Spec

Package: `src/foundations/f-view-projection/`

- `view.ts` — `exportMindPlanView`, `persistMindPlanMap`, `graphToMermaid` / `graphToDot`, `VIEW_FORMATS`
- Uses `expandNeighborhood` from `f-graph-search` and `mindplanRoot` from `f-territory-store`
- Interaction-centric styling: Interaction clusters, `exposes` + `leads_to` edge styles
- `persistMindPlanMap` writes `# MindPlan map`, auto-generated note, **How to read this** legend line, then the mermaid fence
- MUST NOT own MCP tool handlers; `i-export-map` and `i-steer-plan` call into this package

Depends on: `f-domain-model`, `f-graph-search`, `f-territory-store`.

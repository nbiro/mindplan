# View projection

## Purpose

Infra — deterministic Mermaid/DOT projection of the territory graph, plus `persistMindPlanMap` for the auto-refreshed `mindplan/map.md` snapshot after mutations. The projection draws every edge type, so a composition root's `mounts` edges are visible next to `exposes` and `depends_on`. On request it labels each node with its count of active decisions, so a reviewer sees where the recorded reasoning lives; the persisted map never carries the counts, so recording a decision does not rewrite it.

## Shared Substrate Spec

Package: `src/foundations/f-view-projection/`

- `view.ts` — `exportMindPlanView`, `persistMindPlanMap`, `graphToMermaid` / `graphToDot`, `VIEW_FORMATS`
- Uses `expandNeighborhood` from `f-graph-search` and `mindplanRoot` from `f-territory-store`
- Interaction-centric styling: Interaction clusters, `exposes` + `leads_to` edge styles; a `mounts` edge is a bold labeled arrow (Mermaid `==>|mounts|`, DOT `style=bold, label="mounts"`)
- `persistMindPlanMap` writes `# MindPlan map`, auto-generated note, **How to read this** legend line, then the mermaid fence
- MUST NOT own MCP tool handlers; `i-export-map` and `i-steer-plan` call into this package
- **Decision counts.** `ViewOptions.decisions?: boolean`: when true, Mermaid and DOT labels add ` · N decision(s)` to every node with at least one active decision (its active slot's decisions minus superseded ones, from `f-graph-search`); nodes with none are unchanged. Default false; `persistMindPlanMap` never sets it

Depends on: `f-domain-model`, `f-graph-search`, `f-territory-store`.

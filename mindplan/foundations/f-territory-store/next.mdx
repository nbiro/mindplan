# Territory store (shared helpers)

## Purpose

Infra — load/persist territory MDX, scaffolds, frontmatter patches, open_next / discard_next / promote_next, and shared graph node summary helpers used by orient and steer handlers after they leave `f-mcp-runtime`.

## Shared Substrate Spec

Package: `src/foundations/f-territory-store/`

- `store.ts` — existing territory I/O, graph load, scaffolds, patch/open/discard/promote APIs
- Export `summarizeGraphNode(node)` — `{ id, type, state, title }` for blast-radius reachability and similar payloads (moved out of `f-mcp-runtime/server.ts`)
- `config.ts` — `implementation_packages` project config (unchanged in this evolution)
- MUST NOT own MCP tool handlers or CLI parsing

Depends on: `f-domain-model`.

## Acceptance Criteria

- Orient and steer Interactions can import `summarizeGraphNode` from this package
- All existing store/config APIs keep working for compiler, init, and check
- No MCP registration or CLI argv parsing lives here

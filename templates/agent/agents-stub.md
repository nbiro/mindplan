# MindPlan

This repository is modeled as a MindPlan graph (`mindplan/`).

- Before planning or changing code, call `orient_for_work` and place the work on the graph.
- Follow the MindPlan MCP server instructions (the systems dialect). If your host does not show them, read `mindplan/agent/playbook.md`.
- Skills load on demand: `define-entities`, `plan-project`, `review-work`.
